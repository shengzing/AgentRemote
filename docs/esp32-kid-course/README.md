# ESP32 小小发明家课程

面向 8 岁以上、已学过 Scratch 的孩子。课程以 macOS + ESP32/M5StickS3 为基础环境，使用 Scratch 风格积木过渡到 MicroPython。

## 打开方式

直接用 Chrome 打开：

```text
docs/esp32-kid-course/index.html
```

不需要安装 Node.js，也不需要启动服务器。

## 章节结构

1. 课程总览：小小发明家任务书
2. Mac 准备站：电脑、软件和连接
3. Scratch 到硬件：第一次让设备说话
4. 输入和输出：按键、屏幕、灯光与声音
5. 传感器侦探：让设备知道房间发生了什么
6. MicroPython 起步：从积木到代码
7. Wi-Fi 任务站：远程家庭提醒器
8. 综合项目：家庭任务提醒器
9. 展示与复盘：成为小讲师

补充页：`python-basics.html`，用更简单的示例介绍 Python 的基础概念。
补充页：`esp32-intro.html`，介绍 ESP32 是什么以及它的常见能力。

## 主线项目

家庭任务提醒器 / 留言器：

- 解决问题：家人叮嘱容易忘记，孩子需要看得见、能确认的提醒。
- 核心功能：手机或电脑网页发送任务，ESP32 屏幕显示任务，孩子按键确认。
- 学习覆盖：屏幕显示、按键事件、Wi-Fi、网页控制、状态管理、项目展示。
