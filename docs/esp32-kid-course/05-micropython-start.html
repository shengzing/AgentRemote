1MicroPython 和普通 Python
对比普通 PythonMicroPython
住在哪里Mac 电脑里ESP32 芯片里
适合做什么网页、数据处理、电脑工具灯光、屏幕、传感器、Wi-Fi 硬件
标准库很完整精简版，只保留常用部分
安装库pip 可以装很多大库只能装轻量库
控制硬件要借助电脑系统直接用 machine 等模块
共同点变量、循环、条件、函数、列表的写法基本相通
2用 Thonny 连接设备

1. 打开 Thonny

右下角选择 MicroPython (ESP32)。

2. 选择串口

选择你的开发板串口，例如 usbmodem 或 SLAB_USBtoUART。

3. 进入 REPL

如果看到提示符，说明电脑和 ESP32 正在对话。

4. 保存 main.py

把程序保存到设备后，开机就能自动运行。

3五个基础积木的代码样子

任务计数器

count = 0

def confirm_task():
    global count
    count = count + 1
    show("收到", count)

while True:
    if button_pressed():
        confirm_task()

先不急着完整写出硬件代码。重点是知道：变量保存数字，函数打包动作，循环持续检查。

代码阅读三问

  • 哪一行创建变量？
  • 哪一段在重复？
  • 什么条件下会执行 confirm_task？

学习方法先读，再改数字和文字，最后自己写一小段。

5常见错误急救包
错误常因为什么怎么改
IndentationError缩进不对让同一层代码对齐，通常用 4 个空格
NameError变量名拼错或还没创建检查拼写，先给变量赋值
SyntaxError少了冒号、括号或引号看错误行附近有没有漏符号
程序不运行文件名不是 main.py 或没保存到设备保存到设备并重启
6通关检查
小侦探问答：为什么函数有用？

函数把一组动作打包，起一个名字。以后想做这件事，只要调用这个名字，代码更清楚也不容易重复。
