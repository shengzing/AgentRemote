ESP32 是什么？

ESP32 像一颗很小很小的电脑大脑。它可以读按键和传感器，也可以控制灯光、屏幕、声音，还能连接 Wi-Fi。

小电脑传感器Wi-Fi发明
1先分清两个词

ESP32 芯片

ESP32 是乐鑫公司做的一类芯片。芯片本身很小，像大脑一样负责计算和控制。常见型号有 ESP32、ESP32-S3、ESP32-C3 等。

本课程常用ESP32-S3 性能更强，很多小屏幕、麦克风和 AI 小项目都会用它。

ESP32 开发板

开发板是把芯片、USB 口、按键、屏幕、电池接口、传感器等装在一起的小电路板。比如 M5StickS3 就是一块使用 ESP32-S3 的开发板。

一句话芯片是大脑，开发板是给大脑装上眼睛、嘴巴、手脚和电池的身体。

2ESP32 的七种能力

1. 会计算

它可以运行程序、判断条件、保存变量、做倒计时和状态切换。

大脑

2. 会联网

大多数 ESP32 支持 2.4GHz Wi-Fi，可以接收网页指令或发送数据。

Wi-Fi

3. 会无线通信

很多 ESP32 还支持 BLE 低功耗蓝牙，可以和手机或别的设备通信。

BLE

4. 会读输入

它能读按键、温湿度、光线、声音、加速度、距离等传感器。

输入

5. 会控制输出

它能控制 LED、屏幕、蜂鸣器、舵机、继电器等设备。

输出

6. 会串口通信

通过 USB，它可以和 Mac 对话，接收程序、打印调试信息。

USB

7. 会省电

它有低功耗模式，适合做电池供电的小设备。

电池

还能扩展

通过 GPIO、I2C、SPI、UART、PWM、ADC 等接口，可以连接更多模块。

接口
3以 M5StickS3 为例

它身上有什么

  • ESP32-S3 主控芯片
  • 1.14 英寸彩色 LCD 屏幕
  • 可编程按键
  • 六轴 IMU，能感知摇晃和倾斜
  • MEMS 麦克风
  • 小喇叭
  • 红外发射和接收
  • 锂电池和 USB-C 接口

这些能力能变成什么

  • 屏幕：显示任务、表情、倒计时
  • 按键：确认任务、切换模式
  • IMU：摇晃骰子、翻面静音
  • 麦克风：录制声音
  • 喇叭：播放提醒音
  • Wi-Fi：接收网页消息

注意不是每块 ESP32 开发板都有屏幕、麦克风和喇叭。买板子前要看清楚它的配置。

5它能做的项目

家庭任务提醒器

网页发送任务，屏幕显示，按键确认。

房间环境站

显示温度、湿度、光线和噪音。

智能小夜灯

天黑自动亮，天亮自动灭。

浇花提醒器

土壤太干就提醒你给植物喝水。

桌面小闹钟

倒计时结束时提醒你休息。

遥控小灯

手机网页按钮控制灯光。

6它不适合做什么

不能直接接市电

家庭插座电压危险，必须由成人和专业设备处理。

不能当普通电脑用

它没有桌面、浏览器和大型办公软件。

不能随便装大型库

内存和存储很小，适合轻量程序。

不能直接驱动大电机

大电流设备需要电机驱动板和电源保护。

小侦探问答：ESP32 芯片和开发板有什么不同？

芯片是负责计算的大脑；开发板把芯片、屏幕、按键、电池和接口装在一起，让大脑能真正看见世界和做出动作。
