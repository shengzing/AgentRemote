3家长安装步骤

1. 检查 Mac

建议 macOS 12 以上，保留至少 10GB 空间，准备管理员密码。

2. 安装 Chrome

用 Chrome 打开 UIFlow2。Safari 不作为第一选择。

3. 安装 Thonny

从 Thonny 官网下载 macOS 版本，先安装但不必马上使用。

4. 安装 M5Burner

下载 macOS 版本，用它给开发板刷 UIFlow2 固件。

5. 连接设备

使用 USB-C 数据线，插入 Mac。要确认这是能传数据的线。

6. 完成测试

在 UIFlow2 里让屏幕显示“我准备好了”。

4USB 检查方法

打开终端，输入这一行

ls /dev/cu.*

如果看到类似 /dev/cu.usbmodem... 或 /dev/cu.SLAB_USBtoUART，说明 Mac 已经找到设备。

如果找不到换一个 USB 口、换一根数据线；仍不行再按芯片安装 CP210x 或 CH34x 驱动。

不要踩坑

  • 充电线不能传数据，看起来一样但不行。
  • 有些 USB 接口供电不足，换 Mac 直接口试试。
  • 驱动安装后可能需要重新插拔设备。
5安全三条规则

只用低压

课程只使用 USB、电池模块和低压传感器，不接家里插座电。

先断电再接线

想换线、换模块时，先把 USB 线拔掉。

大人检查

舵机、继电器、扬声器等用电较多的模块，由家长先检查。

6通关检查
小侦探问答：为什么要装 Chrome？

因为 UIFlow2 需要 Web Serial 连接开发板。Chrome 对这个功能支持更稳定，Safari 不作为第一选择。
