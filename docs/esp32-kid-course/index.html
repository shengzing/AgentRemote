4家长准备提示

家长负责

  • 安装软件、刷固件、处理 USB 权限。
  • 配置家庭 Wi-Fi，不把密码写进孩子的展示材料。
  • 检查接线安全，只使用 USB 和低压模块。

孩子负责

  • 提出自己想解决的问题。
  • 设计屏幕内容和任务卡片。
  • 观察现象，描述 bug，尝试小步修改。

课程主线：macOS + Chrome + UIFlow2 + Thonny + MicroPython。硬件建议：M5StickS3 或其他 ESP32-S3 开发板。
