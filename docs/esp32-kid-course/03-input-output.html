硬件三兄弟

输入、处理、输出

所有 ESP32 项目都可以先拆成这三块。按键是输入，程序是处理，屏幕和声音是输出。

按键屏幕倒计时
1先认识三种输出

屏幕输出

适合显示任务、数字、表情和状态。我们的最终项目会大量使用屏幕。

灯光输出

适合提醒。比如任务来了亮红色，确认后亮绿色。

声音输出

适合吸引注意，但要有“安静模式”，不然会吵到家人。

2本章项目：10 秒小闹钟

你要做出来什么

  1. 按主键开始倒计时。
  2. 屏幕显示 10、9、8...1。
  3. 到 0 时显示“时间到”。
  4. 播放一声提示，或让屏幕变红。

为什么有用它可以变成刷牙计时、休息计时、专注计时。

代码长什么样

# 先用 UIFlow2 积木搭建，再看类似代码
seconds = 10

while seconds > 0:
    show(seconds)
    sleep(1)
    seconds = seconds - 1

show("时间到")

现在只要能看懂变量和循环。第 5 章再亲手修改。

5通关检查
小侦探问答：倒计时里哪个是变量？

seconds 是变量。它从 10 开始，每次减 1，直到变成 0。
