2最重要的词：阈值

阈值就是分界线

比如光线值低于 300，我们说“房间有点暗”；高于 300，说“光线不错”。

if light < 300:
    show("有点暗，开灯吧")
else:
    show("光线不错")

阈值不是背出来的，要观察真实数据后调整。

三步找阈值

  1. 先把数值显示在屏幕上。
  2. 记录白天、晚上、安静、吵闹时的数值。
  3. 选一个能区分两种情况的数字。

注意阈值太灵敏会一直提醒，太迟钝又会错过。要调到刚刚好。

5通关检查
小侦探问答：为什么不能只看一次传感器？

环境会变化。只看一次可能刚好遇到特殊情况，连续读取才更可靠。
