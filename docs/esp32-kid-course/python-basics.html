Python 基础小词典

这一页只讲最常见的 Python 概念。每个概念都配一个很短的例子，先看懂，再自己改。

Python变量循环函数
1八个基础概念

1. print：让电脑说话

print("你好，Python")

print 会把内容显示出来。

2. 变量：给数据起名字

name = "小豆"
age = 8
print(name, age)

name 和 age 都是变量，像贴了标签的小盒子。

3. 字符串：一段文字

task = "喝水"
print("今天的任务：" + task)

引号里的内容是字符串。加号可以把文字连起来。

4. 数字：会算术

count = 3
count = count + 1
print(count)

这会显示 4。变量可以更新。

5. 条件：如果...就...

light = 250

if light < 300:
    print("有点暗")
else:
    print("光线不错")

条件让程序自己判断。

6. 循环：重复做

for i in range(3):
    print("加油", i + 1)

这会重复三次，像 Scratch 的重复执行。

7. 列表：一串数据

tasks = ["喝水", "带水壶"]

for task in tasks:
    print(task)

列表可以放很多个任务。

8. 函数：把动作打包

def remind(task):
    print("记得：" + task)

remind("喝水")

函数像自制积木，以后可以反复调用。

2合在一起：今日任务清单

代码

# 1. 准备任务列表
tasks = ["喝水", "带水壶", "收衣服"]

# 2. 做一个提醒函数
def remind(task):
    print("记得：" + task)

# 3. 逐个提醒
for task in tasks:
    remind(task)

运行结果

记得：喝水
记得：带水壶
记得：收衣服

试着改一改把“收衣服”换成你自己今天要做的一件事。

3和 MicroPython 的关系

普通 Python

住在 Mac 里，适合做网页、小工具、数据表。

MicroPython

住在 ESP32 里，能控制屏幕、按键、传感器和 Wi-Fi。

共同点

变量、字符串、条件、循环、列表、函数的写法基本相同。

4常见错误小急救
错误样子常见原因怎么改
IndentationError缩进没有对齐同一层代码前面空格保持一致
SyntaxError少了冒号、引号或括号看错误提示附近的行
NameError变量名拼错或还没创建检查拼写，先赋值再使用
没有输出忘记 print 或文件没运行加 print，再运行一次
