Wi-Fi网页消息
1三个新词

Wi-Fi

像家里的无线跑道，让电脑、手机和 ESP32 互相找到。

IP 地址

每台设备的编号。知道编号，网页才能找到你的设备。

请求和响应

网页发出请求，ESP32 收到后做出动作，再返回结果。

2先做最小版本

任务一：Wi-Fi 状态牌

  1. 用 UIFlow2 的 Wi-Fi 积木连接家里 2.4GHz 网络。
  2. 在屏幕上显示连接中。
  3. 连接成功后显示 IP 地址。
  4. 拔掉 Wi-Fi 再看设备如何提示。

安全提示Wi-Fi 名和密码由家长配置，不要写进作品展示页。

连接代码的样子

import network

wlan = network.WLAN(network.STA_IF)
wlan.active(True)
wlan.connect("WIFI_NAME", "PASSWORD")

if wlan.isconnected():
    show(wlan.ifconfig()[0])
else:
    show("连接失败")

真实项目中还要加入等待和重试，不要只判断一次。

3网页控制

1. 网页按钮

做一个按钮，按钮上写“发送喝水任务”。

2. 设备接收

ESP32 收到请求后，把任务文字保存到变量。

3. 屏幕更新

屏幕显示新任务，并进入等待确认状态。

4. 返回结果

网页显示“已发送”，避免一直点按钮。

5网络安全三原则

只用家里的网络

课程项目先在局域网里运行，不对陌生人开放。

不上传隐私

任务内容不要包含家庭住址、密码、成绩等隐私。

失败要友好

断网时显示“连接失败，请稍后再试”，不要假装成功。

6通关检查
小侦探问答：为什么 ESP32 通常用 2.4GHz Wi-Fi？

很多 ESP32 模组主要支持 2.4GHz。家里路由器如果同时有 2.4GHz 和 5GHz，要选 2.4GHz 那个网络。
